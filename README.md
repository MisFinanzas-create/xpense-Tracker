🕐 Reloj digital - Múltiples husos horarios
Una aplicación moderna de reloj digital en tiempo real que muestra la hora actual en múltiples zonas horarias de todo el mundo. Perfecto para equipos globales, viajeros y cualquiera que necesite llevar la cuenta del tiempo en diferentes partes del mundo.

✨ Características
Reloj en tiempo real: Se actualiza cada segundo con la hora exacta
Múltiples husos horarios: Añade y registra hasta 50+ huso horarios diferentes
Formato 24/12: Alternar entre formatos 24 horas y 12 horas (AM/PM)
Pantalla de la hora local: Siempre muestra tu hora local en la parte superior
Información de fecha: Mostrar la fecha actual para cada zona horaria
Tarjetas codificadas por colores: Cada zona horaria tiene un color degradado único
Emojis de país: Identificación visual con emojis de bandera de país
Almacenamiento persistente: Las zonas horarias seleccionadas se guardan en LocalStorage
Diseño Responsivo: Funciona en ordenadores de sobremesa, tabletas y dispositivos móviles
Gestión sencilla: Añadir y eliminar zonas horarias con un solo clic
🚀 Cómo correr
Opción 1: Acceso directo a archivos
Descarga los archivos desde GitHub
Ábrelo en tu navegador webindex.html
¡Empieza a registrar las zonas horarias!
Opción 2: Usar un servidor local
Con Python 3:

python -m http.server 8000
